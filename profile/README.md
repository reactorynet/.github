Reactory gives you enterprise features — **multi-tenancy, RBAC, GraphQL-first APIs, AI-powered workflows, and 40+ composable modules** — on a lightweight Node.js foundation. Ship complex B2B, B2C, and C2C applications with a fraction of the team and cost of a custom build, white-labeled out of the box.

## The Platform

| Repository | What it is |
|------------|------------|
| [reactory-express-server](https://github.com/reactorynet/reactory-express-server) | The platform server — Express + Apollo GraphQL + MongoDB with a module system, durable workflow engine, multi-tenant auth (Passport.js, 15+ strategies), JIT module compilation, PDF generation, and a built-in CDN |
| [reactory-pwa-client](https://github.com/reactorynet/reactory-pwa-client) | The web client — a React Progressive Web Application (MUI), driven largely through configuration with a plugin API for hyper-tailored components |

Supporting the platform: [reactory-core](https://github.com/reactorynet/reactory-core) (shared types, published as `@reactorynet/reactory-core`), [reactory-data](https://github.com/reactorynet/reactory-data) (data/CDN structure), [reactory-native](https://github.com/reactorynet/reactory-native) (React Native mobile client), and [reactory-electron](https://github.com/reactorynet/reactory-electron) (desktop wrapper).
